# Демонстраційний сайт Великогрибовицького ліцею — версія 4

1. Відкрийте `index.html` у сучасному браузері.
2. Використовуйте меню, розділи новин, документів, мобільну версію.
3. Для справжніх фотографій **потрібне інтернет-з’єднання**: зображення посилаються на публічні файли Google Sites, вони не збережені в цьому ZIP. Google може обмежувати пряме відкривання фото з інших сайтів; на цей випадок передбачено естетичні резервні ілюстрації.

Джерело фотографій: https://www.hrybovychi-school.com.ua/ (головна сторінка, світлини шкільних подій та випуску). Перед публічним запуском потрібні оригінальні файли та підтвердження дозволу на використання світлин учнів. Для офлайн-показу директорці бажано попросити в адміністрації оригінальні зображення — тоді вбудуємо їх прямо в архів.

Усі статті й записи документів залишаються демонстраційними. Фотографії показані як архівні й не обов’язково зображають подію зі зразкової новини.
Технічна інтеграція Astro/Pages CMS ще не виконана.
