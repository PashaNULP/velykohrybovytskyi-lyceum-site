# Перевірка компактності внутрішніх сторінок

Контрольні скриншоти створено локально у Chrome 3 листопада 2026 року.

Порівняння 1440×900:

- `before-news-1440x900.png` / `after-news-1440x900.png`
- `before-documents-1440x900.png` / `after-documents-1440x900.png`
- `before-students-1440x900.png` / `after-students-1440x900.png`

Додатково сторінку новин перевірено на розмірах 1366×768, 390×844 та 375×667. Файли `after-news-*` у цьому каталозі містять відповідні результати.

Файл `after-article-1366x768.png` фіксує компактний заголовок, обкладинку та початок тексту окремої новини в межах першого екрана ноутбука.
